# D-ID 有意义基准样片

## 测试目标

用一次短样片同时验证：

1. 合成自定义头像能否被 D-ID 稳定识别和驱动；
2. MiniMax 中文 TTS 能否作为外部音频提交给 D-ID；
3. 汉语连续发音、停顿、`MiniMax` 与 `D-ID` 英文品牌词的口型表现；
4. 生成时延、积分消耗、输出分辨率、音视频时长和编码是否满足后续合成要求。

## 输入

- `synthetic-presenter.png`：完全合成的正面成年主持人，不对应真人；
- `script.txt`：约 15 秒的流程介绍型文案；
- `narration.wav`：由 MiniMax T2A v2 生成。

## 验收标准

- API 成功返回并可下载完整 MP4；
- 主体身份和背景无明显漂移；
- 嘴部在有声段持续运动，在停顿处能自然闭合；
- 中文内容可懂，英文品牌词无明显错口；
- 音频与画面起止差不超过 0.5 秒；
- 记录生成耗时、输出媒体参数和 D-ID 前后积分差。

## 实测结果

- D-ID Talk：`done`；生成与下载总耗时 41.7 秒；
- 积分：12 → 11，准确消耗 1；
- 输出：H.264 + AAC，1254×1254，25fps，11.424 秒，约 1.56 MB；
- 输入音频：MiniMax `speech-2.8-hd`，`female-chengshu`，11.4 秒；
- 画面抽检：人物身份、服装和背景稳定，三个抽检时点嘴型存在明显差异；
- 水印：试用账户在全画面重复叠加 D-ID 标识；
- 本地 ASR 回读：`大家好,这段15秒样片将验证真实的数字人链录,minimax生成中文语音,DID完成口型与面部动作。`；品牌词和主要语义正确，`链路` 被 medium 模型误识别为 `链录`；
- 音视频尾差约 0.064 秒，满足不超过 0.5 秒的标准。

本次证明“合成头像 → MiniMax TTS → D-ID 临时素材上传 → 照片数字人 → 本地下载与 QA”链路真实可用。口型是否达到产品级仍需观看完整视频并做第二人物或第二音色的 A/B 对比，不能仅凭三个取帧判定。

## 人工质量结论

完整观看后，用户验收结论为：**不通过**。

- 口型自然度和音素同步质量明显不足；
- 画面没有手部与上半身动作，主持表现缺乏说服力；
- 当前 V2 Photo Avatar 结果不值得继续通过更换文案、音色或细调参数消耗积分。

因此本实验仅保留为 API 集成与成本基线。产品路线应切换到由真实视频训练的 Digital Twin / Video Avatar，或带自然身体动作的高阶预制主持人；单图 talking-head 不再作为目标方案。
