# 《史境·沉浸式历史阅读》设计契约

## 契约

| 字段 | 约定 |
| --- | --- |
| Entry mode | Revision-led + selected visual target implementation |
| Request revision | 13（通用Book Schema、文件导入与本地书库） |
| Target user and context | 文化内容策划、教育产品团队、博物馆/展陈团队，用于理解“文章如何成为可点选、可聆听、可随文换景的沉浸阅读产品” |
| Desired first impression | 一眼看懂这是“左边读和听、右边看对应历史画面”的沉浸阅读器，而不是游戏、展板或播放器 |
| Visual ambition | Immersive |
| Experience architecture | Source file → Import adapter → Canonical Book Schema → Local library → Book → Chapter → Segment：导入是展厅中的轻量辅助动作，不取代继续阅读/今日推荐；阅读器继续一次只装载一书一章，桌面约40%文字+60%响应视觉，手机为上景下文 |
| Visual constraints | 四幅原创电影感中国历史画面；米纸、墨黑、灰绿、朱砂；不复制参考站的文本、代码或资产 |
| Information constraints | 内置书与用户书统一归一化为版本化Book Schema；每本按章、每章按段组织；模式、正文、音频与画面均可选；JSON完整表达标准模型，TXT/Markdown转换为原文阅读模式；不因缺失AI改写、音频或画面阻断阅读 |
| Operation constraints | 展厅头部增加一枚紧凑“导入”入口；弹层支持点击选择与拖放JSON/TXT/MD，说明导入后结果与当前支持边界；JSON先校验再保存，TXT/MD自动识别书名/章节/段落；提供标准模板下载和本地导入书移除；导入成功后书架即时更新并可直接阅读；保留全部既有阅读、计划、定时和语音操作 |
| State constraints | 用户导入书籍保存到IndexedDB并在重新打开后恢复；阅读进度仍按bookId保存；移除导入书只删除书籍内容，不主动删除其他书与计划；缺图显示文字场景占位，缺音频时使用系统语音，缺模式时只呈现书籍声明的模式；错误文件不写入书库并在弹层内给出可恢复反馈 |
| Environment constraints | 纯静态GitHub Pages；IndexedDB为本机书库；MiniMax音频仍为内置书离线资产，浏览器导入不自动调用云端AI；无后端、登录和分析脚本；HTTP与file://均保持内置阅读，文件导入取决于浏览器File API与IndexedDB能力 |
| Primary journey | 打开展厅 → 点击轻量导入 → 选择有效JSON/TXT/MD → 看到解析摘要与成功反馈 → 新书即时出现在书架 → 进入单章阅读 → 无媒体时仍可选段和系统朗读 → 返回展厅后书籍与进度继续存在 |
| User-defined phases | 定制样例产品；实现类似效果并扩展；使用有意义的经典/历史内容；可新建子项目 |
| Required artifacts | 可运行页面、四幅本地视觉资产、README、设计契约、验证记录、实验日志、design-qa.md、桌面/390px 浏览器证据、研究索引入口 |
| Autonomy authorization | 用户明确要求“定制一个样例产品进行演示驱动，可以新建子项目，实现类似效果并扩展” |
| User-decision boundary | 后续扩展到整套历史内容、真实配音/版权内容、后台 CMS、账号与发布生产系统时再请求产品决策 |
| Observable completion criteria | 仓库存在可审查的Book Schema与两本内置标准JSON；加载器通过HTTP加载JSON且file://回退兼容数据；导入弹层桌面/390px不遮挡或溢出，Escape/遮罩/关闭焦点恢复；有效JSON、TXT、MD均可导入、立即阅读并在重载后保留；重复id安全重命名；非法JSON、空文件、超限文件不写库并给出明确错误；模板下载可用；缺图/缺音频/单模式路径可操作；删除仅针对导入书且需确认；计划、定时、多书及大禹完整旅程无回归 |

## 场景契约

- Scene base：本地响应式历史图片栈，使用 CSS 交叉淡入与轻微 Ken Burns 位移；不再以 WebGL 作为默认视觉。
- Scene persistence：桌面和平板始终占据右侧主舞台；390px 手机占上半屏，文章作为下方阅读面板。
- Foreground controls：章节导航、播放全文、段落选播、上一段/下一段、声音、主题、观景/全屏均为轻量 DOM 控件。
- State-to-scene mapping：
  - `flood`：高水位、雨势、封闭山口、冷色雾。
  - `blocked`：石土堤障被冲开，人物在激流两侧抢险。
  - `channel`：山口打开、水道收束、路线被点亮、人物推进。
  - `settled`：水位下降、田畴与聚落显现、暖光和远山展开。
- Mobile transformation：390px 初始为 320px 上景下文；用户开始朗读后场景收为 112px 粘性视觉条，正文持续可读且当前画面不消失；无底部播放条。
- Fallback：图片失败或 motion 受限时仍显示段落标题/视觉说明；文章与朗读完全独立于视觉资源。

## 视觉方向

| 决策 | 方向 | 可观察约束 | 验收标准 |
| --- | --- | --- | --- |
| 构图 | 左文右景，场景为视觉锚点 | 桌面场景面积不小于一半；手机仍可同时看到场景和文章标题 | 首屏能识别主题、当前章节和主要动作 |
| 层级 | 章节题目与场景关键物优先，控制次之 | 不依赖颜色单独表达当前章；主按钮有文字标签 | 3 秒内能找到“播放演示”和当前章节 |
| 字体 | 中文宋体系承载正文，现代无衬线承载控制 | 正文行长与行高适合连续阅读 | 390px 无横向滚动、正文不小于 16px |
| 色彩 | 米纸、墨、青绿、朱砂；深色主题为夜读 | 两种主题均保持正文和按钮边界 | 主题往返后层级和状态仍清晰 |
| 动效 | 动作解释历史因果，不做无意义漂移 | reduced-motion 关闭镜头漂移、雨线和自动补间 | 无动画时仍能理解章节变化 |
| 密度 | 阅读用户优先的轻量控制体系 | 正文和朗读段落为主角；常驻控件使用窄条、小图标与短标签；不以大卡片、大按钮挤压阅读面积 | 桌面首屏正文占主导；390px 底栏不超过可用阅读区的合理高度且核心控件单手可达 |

## 修订 3 视觉真值与覆盖边界

- 选定视觉：Product Design ideate 第 1 个展示结果，`exec-a00fd1a6-4698-4094-a514-0d460b75115d.png`。
- 参考结构：GatelessGate 桌面 560/880 分栏、移动 405px 场景后接文章；只借鉴阅读节奏，不复制原文与艺术资产。
- 当前视觉：四幅统一的电影感中国历史画面，分别对应“天下困于水、围堵失效、疏川决壅、九州既定”。
- 明确删除：默认开场遮罩、自动 30 秒导演、低多边形场景、常驻大卡片字幕；这些属于被用户否决的修订 2 方向。

## 完整演示导演契约（修订 2）

- 开场：先建立“文章进入空间”的产品心智，主动作直接启动完整演示，次动作进入阅读。
- 分镜：每章包含建立、因果、细节、停留四类节拍；镜头变化必须服务“困境 → 方法 → 日常秩序”。
- 同步：每个节拍只更新一次导演字幕和镜头；章节动作在因果节拍触发；环境声在章切换时连续过渡。
- 段落朗读：正文标题、段落和引文形成可选择的朗读队列；当前段落动态高亮并进入可见区域；点击、Enter/Space、上一段/下一段可随时改写播放位置；用户选段后优先保持用户路径，不被导演自动切章覆盖。
- 声音：浏览器手势后启动由 Web Audio 程序生成的水、风、雨环境层；可随时静音；朗读默认关闭，用户开启后按章朗读。
- 收束：第三章完成后出现可关闭的结尾卡；提供“重新演示”和“返回文章”，并保留最终安定场景。
- 恢复：Escape 依次退出结尾卡、全屏、观景、段落朗读或自动演示；焦点返回触发控件。
- 能力边界：不包含真实配音、版权音乐、视频导出、CMS 或外部资源；这些不影响本轮成品演示的闭环。
