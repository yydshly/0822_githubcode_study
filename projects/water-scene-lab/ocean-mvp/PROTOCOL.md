# Ocean MVP 固定实验协议

## 实验问题

同一艘小型巡航艇在平静海况 A 与有风涌浪 B 中，是否会在同一解析波模型内产生可重复、可解释的水面与船体姿态差异？

本协议只回答内部模型的相对比较，不回答真实海况或船舶安全问题。

## 固定契约

| 项目 | 固定值 |
| --- | --- |
| 模型 | `ocean-gerstner-v1` |
| 种子 | `601` |
| 重力参数 | `9.81` |
| 步长 | `1 / 60 s` |
| 总步数 | `1,200`（20 秒） |
| 预热 | 前 120 步 |
| 统计区间 | 第 121–1,080 步，共 960 步 |
| 场探针 | 每步 5 × 5，共每个案例 24,000 次 |
| 船体 | 长 3.2、宽 1.4、速度 1.0、起点 `(0,-12)`、航向 0 |
| 船体采样 | 艏左、艏右、艉左、艉右四点 |
| A | `seaState = 0.25`，平静海况 |
| B | `seaState = 1.0`，有风涌浪 |
| 契约哈希 | `fnv1a-4a2c196d` |

唯一主要实验因子为 `seaState`。每一波的振幅按 `maxAmplitude × seaState` 派生，因此“振幅和陡峭度同时变化”是该单一语义因子的公开结果，不是两个独立调参项。

## 解析波面

对参数平面坐标 `(u,v)`，方向单位向量为 `D=(Dx,Dz)`：

```text
k = 2π / wavelength
ω = sqrt(gk)
θ = k(Dx·u + Dz·v) - ωt + phase

X = u + Σ(qA Dx cosθ)
Y =     Σ(A sinθ)
Z = v + Σ(qA Dz cosθ)
```

程序同步解析计算 `Pu = ∂P/∂u` 与 `Pv = ∂P/∂v`，法线为 `normalize(Pv × Pu)`。渲染着色器与 CPU 查询由同一固定波表解析，浏览器检查会比较两侧 uniform 与模型结果。

## 世界坐标采样

Gerstner 曲面会水平位移，不能直接把目标世界 `(X,Z)` 当成参数 `(u,v)`。`sampleSurfaceAtWorldXZ` 从 `(X,Z)` 开始，使用四次 Newton 迭代解水平二元方程，再返回曲面位置、法线、残差与 Jacobian。模型测试包含正向位移—逆向恢复往返检查。

四个船体接触点都调用该查询：四点平均高度给出升沉，左右平均差给出横滚，艏艉平均差给出俯仰。它只是可读的视觉响应代理，没有质量、惯量、阻尼、压力积分或推进系统。

## 指标

- 水面高度均值与标准差。
- 波峰高度 P95、坡度 P95。
- 船体升沉 RMS、横滚 RMS、俯仰 RMS、合成姿态 RMS。
- 世界坐标逆解残差 P95/最大值、失败次数。
- 最小水平 Jacobian、法线单位长度误差、非有限值次数。
- 浏览器首帧、帧时间 P50/P95、draw calls、三角形、视口、质量档、控制台与请求错误。

## 首轮通过条件

- 解析导数、逆解往返、陡峭度、法线和非有限值检查全部通过。
- A/B 共享契约且重复运行摘要完全一致。
- B 的水面高度、波峰、坡度、升沉与姿态波动稳定高于 A。
- 桌面临时门槛 P50 ≤ 22 ms；390px 移动档 P50 ≤ 33 ms。
- 桌面双视图、手机 A/B 切换、暂停、重置、reduced-motion 与 fallback 可用。
- 页面无横向溢出、未处理异常、控制台错误或失败请求。

P95 仍记录为尾帧诊断，但当前跨项目临时性能门只规定 P50。一次接近其他验收执行的观察曾出现桌面 P95 约 41.6 ms，随后三次隔离复测为 16.7–20.9 ms；因此基线通过，但仍保留原始上下文与重复范围，不把单次最好成绩包装成跨设备产品级优化。
