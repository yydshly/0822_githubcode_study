# Waterfall MVP 固定实验协议

## Particles4All Bridge Protocol

目标平台：桌面浏览器。近场 Gate 固定以下输入：

所有输入由 `water-scene.particles4all-near-field/v1` 场景契约提供，通用 Scene Runner 负责把 box-normalized 发射器编译成原库 solver-unit 注入；瀑布页面不得另行硬编码粒子包或 Gate 阈值。仓库资产为 [`../scenes/waterfall-impact-near-field.scene.json`](../scenes/waterfall-impact-near-field.scene.json)。

- world drop：`16.8 m`；
- gravity：`9.81 m/s²`；
- ideal impact speed：`sqrt(2gH)`；
- solver injection velocity：`[0, -2.5, 0] u/s`；
- packet：`8 × 6 × 8 = 384` 粒子，spacing 读取原库场景；
- initial pool：Particles4All small / 28K；
- rigid body：原库 sphere，size `0.15`、density `0.5`；
- solver：30 ticks；
- render path：particles；
- Gate：实际注入、ticks、有限值、刚体响应、WebGPU context、桌面布局和错误通道。

视觉 A/B 与近场物理 Gate 是两个不同证据：前者判断破碎层可读性，后者判断局部撞击是否真实调用原库算法。二者不得合并成现实瀑布守恒结论。

## 实验问题

在完全相同的崖壁、主水幕、相机和时间轴下，只增加一层有限的破碎粒子，是否能为瀑布边缘和撞击区提供可重复、可解释的视觉增量？

本协议只比较混合视觉层，不回答真实流量、质量守恒、压力、侵蚀、结构载荷或落水池动力学问题。

## 主水幕契约

主水幕由归一化横向坐标 `u ∈ [-1,1]`、纵向坐标 `v ∈ [0,1]` 和固定时间 `t` 查询。模型返回：

- 三维位置 `position`；
- 横向与纵向切向量 `du / dv`；
- 由切向量构成的法线；
- 仅用于纹理/形变读数的视觉速度；
- 相位和视觉下落距离。

A/B 必须返回逐值相同的主水幕探针；固定结果中两侧 `curtainHash` 都为 `fnv1a-adc38d1c`，探针摘要都为 `fnv1a-5b2f8b1a`。该查询描述网格，而不是液体求解状态。

## 破碎粒子代理

B 的 104 个代理由固定种子生成，分为两组：

1. 边缘/下落代理：从水幕侧缘附近分离，沿预设轨迹下落并给出 `edgeExpansion`。
2. 落点飞溅代理：从固定撞击区向外/向上展开，并给出撞击区域占用率。

每个代理保存类型、发射相位、周期、寿命和轨迹参数。任意时刻的状态由代理表和时间直接求得，不依赖上一帧，不在运行循环调用随机数。生命周期必须满足 `0 ≤ age < lifetime`，位置必须位于固定代理边界中；过期后不可继续计入活动数。

A 不创建破碎层，因此其活动代理、边缘扩展和落点占用必须全部为 0。B 只增加这一层，不能同时打开白沫或雾来放大差异。

## 指标

- 活动代理数均值、P95 和最大值。
- 边缘与撞击两类活动数均值。
- 边缘扩展均值与 P95。
- 落点区域占用均值与 P95。
- 终点活动代理数。
- 非有限值、生命周期违规、边界违规。
- A/B 配置差异键、主水幕哈希、探针摘要、案例哈希和结果摘要。
- 浏览器首帧、帧时间 P50/P95/最大值、>50 ms 长帧、draw calls、三角形、质量档、视口、错误与失败请求。

这些“扩展”和“占用”都是固定视觉代理指标，不使用现实米制或流量单位。

浏览器帧时间覆盖整页同步演示：桌面每帧同时绘制 A/B，移动端也会在验收流程中切换并运行 B。它能回答“这套混合演示的总成本是否过门”，不能归因出粒子层相对 curtain-only 的独立增量成本；若产品需要这一数字，必须另设 A-only / B-only 隔离性能实验。

## 首轮通过条件

- 固定 60 Hz / 1,200 / 120 / 960 协议、代理表、发射器计数和哈希契约通过。
- A/B 只允许 `breakupMode` 不同，主水幕查询、哈希与探针摘要完全一致。
- 同一配置重复运行的案例哈希和结果摘要一致。
- A 的粒子增量为 0；B 同时产生正的活动代理、边缘扩展和落点占用。
- A/B 的白沫与雾都保持关闭。
- 非有限值、生命周期违规与边界违规均为 0。
- 固定证明镜头同时看见上缘、主要落差和撞击区；A 本身仍能读作瀑布，B 的边缘破碎与落点飞溅清楚但不遮蔽地形。
- 桌面平衡档 P50 ≤ 22 ms、P95 ≤ 50 ms；390px 移动档 P50 ≤ 33 ms、P95 ≤ 66 ms，并公开最大帧和长帧次数。
- 桌面双视图、手机单视图切换、暂停、重置、reduced-motion 和强制 fallback 可用；页面无横向溢出、未处理异常、控制台错误或失败请求。

只有数值、真实浏览器和视觉复核共同通过，历史视觉 Gate 3 才能批准 `continue Waterfall hybrid visual baseline`。Particles4All 近场耦合由独立 Stage 6 契约和浏览器 Gate 批准，不能从视觉 A/B 直接推导。
