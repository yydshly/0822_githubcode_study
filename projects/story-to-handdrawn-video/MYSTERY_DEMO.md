# 《封存之后，钟还在走》真实悬疑档案样片

## 为什么是“档案悬疑”而不是惊吓短片

这个样片要验证的不是木刻画风本身，而是悬疑结构能否约束画面、声音与剪辑。五幕分别承担异常、证据链、可信误导、理性翻转和有代价的收束；每个翻转都能回看前一幕中的物件，不依赖旁白临时增加真相。

故事也拒绝把违规进入包装成纯粹的孝心。原始错误报告、录音、口述证词、维护记录和暗道进入被分开保存，既让被遗漏者进入公共记忆，也保留证据之间可以互相质疑的距离。

| 节拍 | 叙事功能 | 视觉证据 | 效果动作 |
| --- | --- | --- | --- |
| 异常 | 提出可验证的不可能 | 未断封条、正在走的钟、三点十七分 | 手电焦点、慢推、低频留白 |
| 证据链 | 建立替代入口 | 暗道、钥匙、鞋印、无文字路线图 | 反向横移、物件硬切 |
| 误导 | 给出可信但未证实的身份 | 长大衣人影、空衣架、旧影像 | 对比加深、投影红光、停顿 |
| 翻转 | 让既有证据改变解释 | 周岚、旧大衣、磁带、空座位 | 放慢、双人对位、证据线汇合 |
| 收束 | 解决事件但保留责任 | 分层物证、破封条、公开运行的钟 | 亮度轻升、拉开空间、无煽情拥抱 |

## 真实生产链

- Codex 内置 imagegen 生成 5 张 1086×1448 分镜；第一张建立调查员、车站、机械钟、三色调色板和木刻语言，后四张引用第一张分别生成。
- MiniMax 中国区 HTTP T2A 使用 `speech-2.8-hd`、`male-qn-jingying`、`calm`、0.94×；生成后以 1.12× 轻度压紧节奏，5 段共 1466 个 API 计费字符。
- FFmpeg 按真实音频时长排列五幕，使用方向相反的慢横移、硬切和低幅度亮度变化，而不复用儿童样片的绘本滑页。
- 最终媒体为 H.264 High 720×960 30fps、AAC LC 32kHz 双声道、135.262 秒；平均 -19.5 dBFS、峰值 -2.0 dBFS；ASS 中文字幕已烧录。
- MiniMax Key 只在生成进程内从仓库外私有环境读取，没有写入页面、媒体清单或提交。

## 适用场景

适合历史档案、企业事故复盘、调查新闻的概念预演、博物馆口述史、合规培训和非暴力悬疑短片。它尤其适合“同一证据在新语境下改变含义”的内容。

不适合仍在司法程序中的真实案件、需要精确复原的犯罪现场、可能暴露未成年人或证人身份的材料，也不应把模型生成画面作为事实证据。此类项目必须区分事实、推断和艺术重建，并保留人工审阅与来源说明。
