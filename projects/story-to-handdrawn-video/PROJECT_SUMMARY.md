# story-to-handdrawn-video 项目总结

## 1. 最终结论

上游 `story-to-handdrawn-video` 的核心不是“理解故事的模型”，而是一套把静态图片转换为手绘揭示视频的确定性表现框架：它把彩色图派生成线稿/黑白层，再由时间轴逐步揭示线条、文字和彩色图，并用 FFmpeg/Remotion 输出视频。

本研究在它之上补齐了知识视频所需的上游与下游：

`学习目标 → 故事讲解 → 五幕结构 → 效果契约 → 图片 → TTS → 确定性合成 → 网页播放与交付`

因此，最终成果已经不只是“20 种风格的库演示”，而是一个可验证的知识可视化叙事原型。故事讲解决定观众学到什么，图片决定主要审美与信息表达，TTS 提供稳定声音，原库风格和合成机制负责把素材组织成具有手绘感、诗卷感或标准讲解感的成片。

## 2. 上游、本研究与模型分别负责什么

| 层级 | 负责内容 | 不负责内容 |
| --- | --- | --- |
| 上游库 | 手绘风格配方、黑白/彩色层、遮罩揭示、时间轴和视频合成 | 不自动保证故事正确、画面有意境或角色连续 |
| 本研究的产品层 | 知识目标、五幕叙事、效果契约、流程状态、样例隔离、网页交付与证据 | 不把任何模型输出假装成已核验事实 |
| Codex/图像模型 | 关键画面、视觉锚点、角色和场景连续性精制 | 不是浏览器可直接调用的匿名接口 |
| MiniMax | 文本方案、自动生图和中文 TTS；当前最稳定的角色是 TTS | 质量仍受提示、模型版本和参考图约束 |
| FFmpeg/确定性渲染 | 时长、转场、字幕、音画组合、编码和规格输出 | 不创造故事含义，也不能挽救错误分镜 |

最重要的产品判断是：不要先让用户选画风，而应先确定“谁要学会什么、容易误解什么、用什么生活经验进入”。随后才选择与内容相符的视觉、声音和时间语言。

## 3. 已实现的增强

1. **研究页**：完整说明上游机制、20 种风格、使用边界和扩展方向，并内置多类真实成片。
2. **故事—效果导演**：把家庭记忆、科学解释、儿童成长、悬疑、品牌、诗性、古诗词和科技人文映射为不同叙事弧、视觉语言、声音与节奏。
3. **知识故事工作台**：从主题、受众、时长、学习目标、误解、入口和事实依据七项信息生成五幕教学方案。
4. **独立生产台**：提供目标、方案、分镜、声音、成片、交付六步流程；新项目与预设样例严格隔离。
5. **可执行效果契约**：研究推荐不再是一段说明文字，而是贯穿交接、方案、分镜提示、渲染和导出的结构化项目配置。
6. **真实 MiniMax 链路**：服务端保存 Key，浏览器只提交结构化任务；支持方案、图片、音色/语速 TTS 和任务状态。
7. **三种渲染配方**：`standard`、`handdrawn`、`poetic` 由同一效果契约选择并进入 FFmpeg 合成。
8. **网页内交付**：成功生成后在页面直接播放本次 MP4，同时提供下载和不含密钥的项目清单。
9. **质量分层**：快速自动路线由 MiniMax + FFmpeg 完成；最高质量路线明确标记为 Codex/Agent 协作精制，避免把不同能力混成一个虚假“一键模型”。

## 5. 最适合的使用场景

| 场景 | 价值 | 推荐效果 |
| --- | --- | --- |
| 古诗词、文学与文化传播 | 把意象、空间、声音和关键词关系显性化 | 诗卷讲解、明亮东方、夜色水墨 |
| 科学与生活知识微课 | 用误解—机制—证据—迁移替代概念堆砌 | 白板手绘、标准讲解 |
| 博物馆、公共文化与公益科普 | 低成本形成统一栏目视觉，并明确事实/艺术边界 | 档案、版画、手绘解释 |
| 品牌工艺与技术教育 | 让选择、代价、过程和证据成为故事主体 | 工艺手绘、结构化叙事 |
| 儿童成长和分龄教育 | 用行动变化而非成人说教表达成长 | 暖光彩铅、轻节奏旁白 |
| 个人体验转知识传播 | 以停电、记忆等情绪入口连接系统知识 | 科技人文、诗性解释 |

它不适合高动作连续视频、要求精确口型的数字人、零审阅的高风险医学/法律内容，以及必须完全自动保持长篇人物一致性的制作。

## 6. 已验证的代表样例

研究页已经收录家庭记忆、知识解释、儿童成长、悬疑档案、品牌工艺、诗性独白、古诗词夜色、古诗词明亮欣赏、诗卷讲解、电力科技人文和“为什么 AI 那么耗电”等样例。它们验证的不是单纯换皮，而是“故事结构、画面证据、声音节奏、字幕版式和渲染配方”共同改变最终效果。

## 7. 下一阶段产品化方向

优先级不应是继续增加风格数量，而是提升故事与效果的对齐质量：

1. 建立“教学目标—事实依据—五幕结构—画面证据”的评分与人工审阅门。
2. 用参考图、角色卡、场景拓扑和色彩脚本增强跨镜头一致性。
3. 将每次生成固化为可重放的项目版本，记录模型、提示、成本、素材和授权。
4. 为单幕重写、单图重生、单句重配音和局部重渲染建立增量工作流。
5. 云端部署时增加身份认证、任务队列、限额、对象存储、回调和审核状态。
6. 用理解率、误解修正率和迁移能力评估教育价值，而不只看播放量。

一句话概括产品意义：**把“模型能生成素材”提升为“人能够设计、核验并交付有教育意义的视觉故事”。**
