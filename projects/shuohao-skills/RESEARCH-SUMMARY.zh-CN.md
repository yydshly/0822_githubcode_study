# shuohao-skills 能力探索总结

## 研究状态

`archived`：库能力与边界探索已经完成；《潮痕》短剧投产尝试未通过叙事前置质量门，停止继续生成视频。

上游项目：[eternityspring/shuohao-skills](https://github.com/eternityspring/shuohao-skills)  
固定提交：`0e5eb688ebf1b45e45c9bec31543aaa59e67c7bc`

## 一句话结论

shuohao-skills 是一套面向**已有小说**的结构化短剧改编工作流：把小说逐层整理为大纲、角色、美术、剧本、分镜和图像/视频模型输入，并用确定性脚本检查格式、引用、时长和切点。它不是小说创作器、故事质量评审器，也不是自动成片系统。

## 研究问题

1. 仓库能否在 Windows/Node.js 环境运行？
2. 除了自带夹具，能否驱动一部新故事形成短剧资料？
3. 哪些能力来自原库，哪些来自大模型和外部生成器？
4. 结构化资料通过校验后，是否足以生成连续可用的视频？
5. 库的真正价值、边界和后续研究重点是什么？

## 研究内容与过程

### 1. 固定上游并复现自带样例

- 以 Git submodule 固定上游提交。
- 运行 outline、characters、art、script、storyboard 五个模块及合成报告自测。
- 1,262/1,262 项自测通过。
- 复现上游《渡口》夹具的五阶段报告，确认数据管线、校验器和 HTML 报告可运行。

### 2. 用原创《潮痕》探索完整流程

- 从原创故事生成 6 集大纲、5 名角色、4 个场景、7 件道具、6 集剧本。
- 形成 59 段、193 镜、682 秒的分镜结构。
- 生成角色、场景、道具参考图和 193 张逐镜图片。
- 导出 ChatArt/H3 提示词、图片上传顺序、字幕、声音表和剪辑时间线。
- 原库五层 validate 全部通过。

这些结果证明库能把已有故事组织成规模化、可追踪的结构化资料，但只证明“规格合法”。

### 3. 增加原库没有的检查

- 增加 11 项故事逻辑与证物时序审计，并在发现后回写修复。
- 增加 58 个相邻段首尾状态审计。
- 增加中文生产入口、图片 QC、成本估算和视频登记控制台。

这些属于本研究的大模型分析和工程扩展，不是上游库的原生能力；而且它们发生在大量资料生成之后，属于事后补救。

### 4. 用连续视频做最小验证

- 生成 E01-01 与 E01-02 两个连续视频样本，并保留一个早期 E02-01 H3 演示。
- E01-01 结束于人物奔向门、准备开门；E01-02 却回到之前的位置打开盒子。
- 人物目标、空间位置和动作因果发生回退，两段无法自然连接。

两个样本不能证明 59 段逐段都会失败，但足以证明当前管线缺少投产前叙事质量门。继续扩大视频生成只会放大返工成本，因此实验停止。

## 能力归属与边界

| 环节 | 主要能力来源 | 结论 |
| --- | --- | --- |
| 小说分块、阶段结构、ID、时长、引用和导出 | shuohao-skills | 强，可确定性验证 |
| 大纲内容、人物动机、剧本动作、分镜语义 | 大模型 | 受提示和上下文影响，库不保证质量 |
| 角色图、场景图、道具图、关键帧 | 图像模型 + 人工/模型选择 | 原库只提供契约，不提供结果保证 |
| ChatArt 导入顺序、中文控制台、逻辑/衔接审计 | 本研究扩展 | 不是上游原生能力 |
| 真实动作、插值、口型与视频首尾状态 | MiniMax H3 / ChatArt | 只能由真实生成结果验证 |
| 小说原型质量、全剧因果和改编取舍 | 当前管线缺失 | 本次失败的主要前置缺口 |

## 最终研究结论

### 已验证的价值

- 把已有小说改编过程拆成五层结构化规格。
- 为多轮大模型协作提供稳定的字段、ID 和交接物。
- 自动发现格式、引用、时长、切点和部分提示词结构错误。
- 生成可追踪、可审计、可重复导出的研究材料。

### 未解决的关键问题

- 不判断小说原型是否优秀或适合短剧。
- 不保证人物欲望、冲突升级、选择和结局成立。
- 不建立全剧因果图、人物知识状态和空间/道具状态时间线。
- “小说拆分”更接近结构化整理，尚不等于高质量短剧改编。
- 结构校验通过不等于视频可用，图片齐全也不等于相邻动作连续。

### 对《潮痕》资料的最终口径

- 59 段、193 镜和 193 张图片：实验资料，不是正式投产资产。
- 11 项逻辑修复、58 个边界审计：事后补救证据，不能反向证明故事合格。
- 3 个真实视频文件：流程验证样本；正式采用 0/59。
- 视频生产决策：停止扩大生成。

## 后续若重启，应从哪里开始

1. 小说原型评审：人物欲望、核心矛盾、关键选择、人物弧、伏笔和结局。
2. 全剧因果图：每场进入原因、变化和退出结果。
3. 状态时间线：人物位置、知识、目标、道具持有和物体开合。
4. 真正的短剧改编：允许删线、合人、改序、补桥和重写场景。
5. 先做文字走查或低成本静态预演，再只生成 2～3 个连续视频小样。
6. 小样连播通过后，才恢复规模化图片和视频生产。

## 归档判断

这次研究不再继续深入。它的成果不是一部完成的短剧，而是明确证明：

> 结构化拆分工具能够提高资料组织和机械校验能力，但无法替代小说质量、因果逻辑和短剧改编能力；这些前置能力缺失时，继续生成视频没有价值。
