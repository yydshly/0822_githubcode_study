# 《潮痕》中文生产总控 · 交付契约

- Entry mode：Revision-led，在现有报告基础上新增主入口并修复跨页面引导。
- Request revision：2；用户确认继续后，补齐统一参考图并让主入口动态更新。
- Target user and context：中文用户，在本地浏览器中查看小说到视频的制作准备情况，后期按需生成图片和 H3 视频。
- Desired first impression：一眼看懂完成了什么、缺什么、下一步应该点哪里。
- Visual ambition：Functional。
- Experience architecture：Editorial Flow。
- Visual constraints：统一深色中文工作台；不把技术英文作为第一层信息；状态不能只靠颜色表达。
- Information constraints：严格区分故事结构、统一参考图、逐镜图片、真实 H3 视频和生产文件的完成度。
- Operation constraints：纯静态本地文件；不新增后端；所有链接必须指向现有文件或明确标记缺失。
- State constraints：支持全部、图片齐全、缺图三种段落筛选；空结果有说明；链接状态可识别。
- Environment constraints：Windows 本地 `file://` 打开；桌面 1440px、平板 768px、手机 390px。
- Primary journey：打开主入口 → 阅读下一步建议 → 进入角色/场景参考页 → 筛选目标段落 → 打开中文说明、逐帧提示词、上传顺序、ChatArt 提示词或导入 JSON → 返回主入口。
- User-defined phases：主入口指导；关联具体页面；修正格式与缺失表达；补齐统一参考图。
- Required artifacts：`index.html`、可重复生成脚本、两个分镜报告的主入口返回链接、桌面与手机浏览器证据。
- Autonomy authorization：用户已明确“确定”，授权在本地项目范围内直接实现并验证。
- User-decision boundary：147 张逐镜图和后续 H3 视频属于后续视觉生产批次，不在本轮 5 张统一参考图交付范围内。
- Observable completion criteria：入口数据与 JSON/文件系统一致；7 个报告入口有效；59 段均可筛选定位；生产文件入口完整；移动端无页面级横向溢出或导航遮挡；键盘可达且焦点可见。
