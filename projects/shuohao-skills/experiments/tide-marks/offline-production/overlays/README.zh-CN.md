# 《潮痕》后期叠加素材

## E06-10/f2 手机通知

- 文件：`E06-10-f2-phone-notification.svg`
- 用法：在许知遥手机屏幕四角跟踪后缩放/透视贴合，出现 1.0～1.5 秒。
- 声音：一次轻震和一次克制提示音。
- 边界：这是虚构剧情界面，只表示材料已进入复查流程；不得添加公安、法院或真实机构标志，也不得改写为立案、判决、有罪、无罪或翻案完成。
- SVG 外围透明，可在剪辑软件中直接导入；若软件不支持 SVG，再导出透明 PNG，勿截图白色画布。

## E06-08/f3 接收回执

回执是可选项，不是故事成立的必要信息，因此暂不制作固定图形。如后期确需添加，只能使用无机构标识、无真实编号的虚构中性回执，并保持短暂、不可读，不能暗示证据链已经完成法律认证。
