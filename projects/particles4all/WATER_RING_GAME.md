# 水中套圈场景原型

## 目标

基于固定版本 Particles4All，验证局部液体—刚体能力能否转化为可玩的网页水压套圈游戏，而不是继续扩展宏观水场景。

在线入口：`docs/demos/particles4all/water-ring-game/`

## 能力归属

| 层级 | 实现 |
| --- | --- |
| `U0` 源库 | PBF 水体、torus 刚体、Shape Matching、浮沉、碰撞、SSFR |
| `E1` 扩展 | Runtime Adapter 流体包注入、圆环位姿采样、可观察位移 |
| `G1` 游戏 | 水压按钮、目标区域、计分、键盘操作、引导演示 |

## 当前验收

1. 页面必须运行固定上游 WebGPU Runtime，而不是独立水动画。
2. 五个圆环必须来自源库原生 `torus` 形状。
3. 每次按钮操作必须增加求解器内流体粒子，并推动圆环产生可测位移。
4. 页面必须显示新增粒子数、最大抬升和最大位移。
5. 支架暂时只标记为游戏目标判定层，不宣称已完成细支架物理碰撞。
6. 重置、SSFR/particles 切换、键盘 A/S/D/R 和 WebGPU 错误提示必须可用。

## 下一 Gate

只有在水压能够稳定形成可玩圆环位移后，才进入“真实支架碰撞体”研究：先验证细支架粒子采样、圆环穿杆和稳定挂接，再决定是否值得修改源库边界/碰撞构造。
