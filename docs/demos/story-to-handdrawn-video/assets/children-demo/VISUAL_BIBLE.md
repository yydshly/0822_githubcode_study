# 《她先学会听风》视觉锁

## 角色锁

- 小满：约 8 岁的中国女孩，黑色齐耳短发和不齐的刘海，圆脸，深色眼睛。
- 服装：芥末黄色连帽风衣、蓝绿色长裤、暖红色帆布鞋、小型深蓝布书包。
- 情绪弧线：期待 → 用力与急躁 → 安静观察 → 专注修补 → 平静自信。

## 道具锁

- 手工燕子形纸鸢：奶油白纸面，钴蓝色不对称翅纹，暖红布头短尾；第三幕有右翅裂口；第四幕增加由蓝色奖带改成的长尾翼与可见补丁；第五幕必须保留修补痕迹。
- 山坡：春季草坡、芦苇、杨树和远处旧水塔，避免城市高楼与现代广告。

## 风格锁

- 暖光童画绘本，手绘水粉与彩铅混合，粗糙纸纹，可见但柔和的铅笔轮廓。
- 低饱和草叶绿、芥末黄、天空灰蓝；蓝色奖带是后半段的视觉强调。
- 3:4 竖幅，低机位接近儿童视角；人物动作方向清楚；画面下方保留字幕安全区。
- 不生成文字、数字、徽标、水印、伪文字或对话框；不追求塑料般平滑的 3D 效果。
