# 《枫桥夜泊》视觉锁

- 画幅：16:9 横屏；最终 1280×720。
- 媒介：宋元山水册页感的当代水墨插画，宣纸纤维、积墨、淡赭与极少朱砂渔火；不是照片，也不仿制具体名家作品。
- 时间：深夜贯穿五幕，不进入日出；冷靛灰月色逐幕加深，终幕仍保持夜色。
- 固定物：同一艘低篷木客船、同一名深色布袍旅人、江岸枫树、两点渔火、远处寺塔与石桥。
- 人物：仅作为诗中视角，侧面或背影；不做张继历史肖像，不增加戏剧动作。
- 空间：客船始终在江面近景；寺院只在远景/中远景出现；终幕钟声以克制的墨色涟漪表现，不画可见声波特效。
- 禁止：任何图中文字、印章、落款、水印、现代灯光、现代建筑、电线、玻璃窗、现代船只、电影特效光束。
- 历史边界：服饰、船、桥和寺院均为依据诗意的艺术化概括，不标称考古复原。
