# 《封存之后，钟还在走》视觉锁

## 角色锁

- 沈砚：中国女性调查员，约 30 岁，黑色齐耳短发、炭黑野外长外套、铁锈红围巾、深色皮手套与旧帆布挎包。
- 周岚：末任站长的成年女儿，穿父亲留下的深色长站务大衣；第四幕主动交出钥匙，第五幕与沈砚保持克制距离。
- 人物弧线：观察异常 → 连接证据 → 拒绝超自然捷径 → 接受复杂证词 → 公开而不浪漫化地归档。

## 证据锁

- 机械钟：无数字、只有刻度；第一至四幕处于封存空间，第五幕在公开视野中运行。
- 铁钥匙、维修暗道、鞋印、长大衣、磁带和破损封条必须各自承担不同证据功能，不能只作为气氛装饰。
- 铁锈红只用于围巾、封条、钥匙/路线、投影光、磁带线与证据连接线，形成可追踪但不代替逻辑的视觉索引。

## 风格锁

- 粗粝木刻社论插画：手刻边缘、油墨颗粒、旧纸纹与硬阴影，保持成熟、非暴力、非超自然。
- 严格三色：炭黑、旧纸米黄、警示铁锈红；不得混入高饱和蓝绿或摄影质感。
- 3:4 竖幅，下方约 16% 保留低细节字幕安全区；不生成文字、数字、标签、徽标、水印或伪文字。

## 五幕提示词意图

1. 封条未断但机械钟在走，以沈砚与手电建立角色、空间和异常。
2. 暗道、钥匙、鞋印与无文字路线图形成证据链，不提前揭示身份。
3. 长大衣人影与空衣架制造可信误导，明确只是人类轮廓。
4. 周岚穿旧大衣交出钥匙；磁带、空出的儿童座位与钟完成理性翻转。
5. 原报告、口述与物证分层公开；大衣挂在明处，钟不再秘密上弦。
