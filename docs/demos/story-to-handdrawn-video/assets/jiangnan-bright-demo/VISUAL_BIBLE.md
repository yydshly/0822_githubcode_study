# 《忆江南》明亮诗境视觉锁

- 画幅：16:9 横屏，适配 1280×720 成片。
- 媒介：当代中国青绿设色手绘，水彩与矿物色叠染在暖宣纸上；可见纸纹、干湿笔边缘，不做霓虹数码渐变。
- 固定空间：同一段江南春水、同一座浅灰石拱桥、白墙黛瓦水巷、远山；地标方向在五幕中可追踪。
- 固定观看者：同一叶深木色小舟、同一位青蓝长衫的成年回望者，只作为视觉尺度，不生成可辨识历史人物肖像。
- 色彩锁：日出朱红 `#E84D2A`、江花珊瑚红 `#F05A45`、春水孔雀绿 `#159A86`、天光湖蓝 `#56B8D6`、暖宣纸 `#F4E3B2`、黛瓦深蓝灰 `#243F4A`。
- 连续性：01 建立全景锚点；02 进入水巷；03 突出日出光路；04 贴近花水红绿对照；05 回到稍远全景并保留同一桥、舟和花树。
- 禁止：图中文字、书法、印章、水印、现代建筑、塑料船、霓虹、高楼、摄影写实、动漫脸、无来源的宫殿。
