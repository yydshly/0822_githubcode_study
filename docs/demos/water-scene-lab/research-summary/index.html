01 · SOURCE CAPABILITY MAP

源库真正提供的能力。

以下能力来自上游 README 和未修改 Runtime；场景名称不是源库能力。

01 · SOLVER

统一粒子物理

水和刚体都表示为粒子，在同一空间网格与约束循环中求解。

PBF · Shape Matching
02 · COUPLING

液体—刚体双向作用

水能推动物体，物体会排开和扰动水；浮力由统一求解自然产生。

浮沉 · 排水 · 碰撞
03 · SURFACE

各向异性表面重建

将离散粒子邻域重建为更平滑的液体轮廓，而不是直接显示球形粒子。

Anisotropic Kernels
04 · RENDER

屏幕空间流体渲染

利用深度、厚度、法线和窄域滤波构成 SSFR 连续水面。

Narrow-range Filter
05 · MATERIAL

表面张力与黏附

支持液柱断裂、液滴聚合和不同材料观感的定性实验。

Tension · Adhesion
06 · INTERACTION

原生互动与质量档

推水、注水、抓取刚体、移动箱壁，以及 small / medium / large 粒子规模。

WebGPU Compute

03 · EXTENSION ROUTES

基于这些能力，可以扩展什么？

扩展分为“场景输入可实现”和“必须新增求解器”，不能混为一谈。

E1 · 可基于原库继续

场景与边界扩展

  • 参数化喷口与持续来水
  • 多个静态 box 障碍
  • 局部平移/旋转闸门
  • 开放出流与局部采样
  • 高度场或 glTF → SDF/体素碰撞
HYBRID · 近场组合

可使用的场景

  • 浮具、漂浮物和水上救援教学
  • 储液箱、注水、灌装与喷流原型
  • 游戏中的水体机关和清障互动
  • 瀑布落点、水潭冲击等局部英雄效果
  • 船体/岸边等局部液固交互验证
STOP · 不能靠包装得到

需要新求解能力

  • 完整海洋、长距离河流和流域模拟
  • 泡沫、喷雾、多液体和明确黏性模型
  • 泥沙、冲刷、侵蚀、渗流和材料断裂
  • 复合船体与非均匀质量
  • 工程流量、承载或洪水风险结论
E1 · 已验证

局部落水冲击

使用 Adapter 注入粒子并读取刚体响应，证明原库可被包装为局部效果模块。

E1 · 已验证

闸门喷流

验证持续来水、障碍与水体响应；这是场景边界扩展，不是新液体算法。

STOP · 失败边界

复杂容器与任意碰撞体

现有箱体边界不足以可靠支持复杂中空容器，已明确停止独立造引擎。

ARCHIVED · 2026-08-25

保留为 WebGPU 局部液体—刚体研究基线。

最适合有限容器注水、喷流、局部冲击、浮沉和障碍互动。宏观河海只可把它作为近场模块；当前不包装成通用水体 SDK，也不把流域或工程水力学算作源库能力。
