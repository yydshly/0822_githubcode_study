CURRENT BOUNDARY

这是“可玩性验证”，还不是最终玩具模拟。

  • 圆环受水推动和姿态变化是真实源库计算。
  • 当前支架是目标判定层，尚未完成细支架的粒子碰撞与稳定挂接。
  • 命中表示圆环进入目标空间，不等于已经证明真实穿杆过程。
  • 若位移与命中节奏成立，下一步才值得研究静态支架碰撞体。
