水与圆环

E2 · Solver 扩展

装置、喷流与静态碰撞

目标杆、底座、顶帽、泵体和三枚喷口进入源库 WebGPU 固体渲染通道；底座圆柱、细杆圆柱和顶帽球体同时进入粒子位置约束，每轮在 Shape Matching 后消除水与圆环的穿透。

G1 · 新增玩法

对准引导、落座与计分

真实水流先推动圆环；进入杆口后，游戏层辅助校正中心与孔轴并引导下落。最终接触由求解器静态碰撞限制，连续稳定采样后计分。引导保证可玩性，但不再允许环粒子穿入杆和底座。

CURRENT BOUNDARY

杆、底座和顶帽已有求解器碰撞；自动穿杆仍保留游戏引导。

  • 抬升、冲击、漂移和圆环刚体姿态由源库计算。
  • 杆、底座、泵体和喷口与水、圆环共用 3D 世界坐标；页面不使用 HTML 几何覆盖画布。
  • 杆、底座和顶帽采用解析碰撞体，每轮在刚体形状匹配后投影穿透粒子，并按粒子半径保留表面间距。
  • 当前自动对准与沿杆下落仍使用 Runtime 捕获引导，以保证游戏可完成；下一步可研究摩擦、反弹和取消捕获后的纯物理自由玩法。
